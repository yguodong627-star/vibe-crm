# 客簿 · 单人 CRM（客户 / 项目 / 任务 / 报价）

纯前端、打开即用、免费、无账号、无广告。数据只存在你自己浏览器的 IndexedDB（不可用时回退 localStorage），**不会上传**。

在线使用：https://yguodong627-star.github.io/vibe-crm/

## 适合谁
自由职业者、独立设计师/开发者、一人工作室、小团队里"自己管自己客户"的人。

## 典型场景
- 记下每个客户的阶段与下次跟进日期，打开页面就知道今天该联系谁
- 一个客户下挂多个项目、项目下挂任务，交付日和任务截止日一屏看清
- 现场做一份报价，改完数量单价即时算出小计/折扣/税额/总计/人民币大写，直接"打印 / 导出 PDF"
- 把表格里的客户、任务用 CSV 批量导入，或导出给会计/备份

## 功能
- 四张表：客户、项目、任务、报价，互相关联（客户→项目→任务；报价→客户/项目）
- 表格视图 + 看板视图（看板可拖拽改状态，手机上用卡片右下角下拉框）
- 搜索、筛选（状态/客户/项目/日期）、排序
- "今天"页：逾期 / 今天 / 未来 N 天（可设置）提醒，待回复报价金额、年度已接受报价
- 报价单：金额全部整数运算（单价=分，数量=百分位，税率=万分位），四舍五入到分；折扣不会超过小计；自动编号 Qyyyy-NNNN；人民币大写
- 报价单打印样式（A4），浏览器打印窗口里目的地选"另存为 PDF"即可
- CSV 导入（带预览与逐行校验，按名称自动关联、可自动新建客户/项目，重复行跳过）、CSV/JSON 导出
- JSON 完整备份与恢复（恢复为覆盖式）

## 已知限制（请先读）
- **单人使用，不支持多人协作**，也没有云同步；换设备请手动导出 / 导入备份
- **提醒只在你打开本页时计算和显示，关闭浏览器不会通知**，也不发邮件/短信
- 清理浏览器站点数据会丢失所有数据，请定期"导出备份"
- PDF 依赖浏览器的"打印为 PDF"，不同浏览器页边距选项略有差异
- 仅人民币；税率为单一税率，不处理多税率/含税价反算
- 中文衬线字体在无宋体的系统上会回退为系统默认字体
